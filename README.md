# SahiMilo Kisan

Farmer support website for the Sitamarhi pilot. The live site currently runs on Cloudflare-backed Sites hosting and stores requests in its D1 database. A separate Supabase project has been prepared for a future migration. Do not switch production data until the new deployment and access controls are verified.

This repository is a source mirror. Generated build archives, local caches, and secrets are excluded.
